Quick Start

Get running in under two minutes

1. Download and run the Windows single-file installer or extract portable ZIP:

ssh-client-setup-v0.0.10-windows-x64.exe

2. The app opens your browser to the GUI automatically. Or navigate to:

http://localhost:4000

3. On Linux, extract the tarball and start:

tar -xzf ssh-client-linux-x64.tar.gz -C ~/.local/ssh-client
~/.local/ssh-client/bin/ssh_client start

Architecture Invariants

Design decisions prioritizing security and minimal overhead

01 / TRANSPORT

Erlang Native :ssh Engine

Eliminates reliance on external ssh binaries or OpenSSH-for-Windows. Connects directly via OTP :ssh_connection and :ssh_sftp in BEAM memory.

02 / CREDENTIALS

OS Credential Stores

Secrets never touch plaintext configs. Direct integration with Windows Credential Manager and Linux Secret Service (libsecret) with memory-only passphrase caching.

03 / RESOURCE EFFICIENCY

Focus-Aware Polling

Background hosts dynamically throttle telemetry checks. Non-interactive exec channels are used for metrics rather than holding open idle PTY shells.
