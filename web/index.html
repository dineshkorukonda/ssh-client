Capabilities

Engineered for production reliability.

Every subsystem was architected to eliminate bloat, enforce memory safety, and prevent data leakage.

01 • CORE RUNTIME BEAM VM

Erlang Native :ssh Engine

Eliminates reliance on external ssh CLI binaries, Cygwin, or OpenSSH-for-Windows wrappers. Connects directly via OTP :ssh_connection and :ssh_sftp in memory. Handles flaky connections, automated keepalives, and sub-millisecond crypto handshakes with zero memory leaks.

No OpenSSH binary required Sub-millisecond auth Erlang OTP 27
02 • SECURITY DPAPI / Secret Service

Hardware-Backed Keychain

Credentials and private keys never touch plaintext configuration files on disk. Direct integration with Windows Credential Manager and Linux Secret Service (libsecret) with memory-only passphrase caching.

03 • FILE TRANSFERS DUAL-PANE

Side-by-Side SFTP Explorer

Side-by-side local vs remote filesystem browser with drag-and-drop transfers, path breadcrumbs, search filters, permission inspectors, and a built-in modal editor for fast configuration editing.

04 • PERFORMANCE SMART POLLING

Focus-Aware Polling

Background hosts dynamically throttle telemetry checks when their tabs or windows are out of focus. Non-interactive exec channels are used for metrics rather than holding open idle PTY shells.

05 • MAINTENANCE IN-PLACE

Seamless Auto-Updater

Single-click update checks against GitHub Releases. Verifies SHA256 checksums, downloads staging artifacts, backs up changed files, and restarts without wiping configuration or host databases.

06 • PRIVACY & FREEDOM ZERO PHONING HOME

100% Offline-First. Completely Air-Gapped.

We don't resell access tokens, track user telemetry, or require external cloud logins. Your server lists, credentials, session histories, and private keys never leave your device. Fully operational behind strict enterprise corporate firewalls and defense air-gaps. MIT Licensed open source.
